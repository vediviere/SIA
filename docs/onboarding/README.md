\# Onboarding técnico



Esta sección reúne la documentación necesaria para que nuevos integrantes comprendan la configuración local, las reglas de trabajo y los criterios utilizados por el equipo durante el desarrollo de SIA Platform.



\## Documentos



\* \[Onboarding técnico inicial](TECHNICAL\_ONBOARDING.md): introducción a la arquitectura, estructura, configuración y flujo de trabajo del proyecto.

\* \[Reglas de trabajo del equipo](TEAM\_WORK\_RULES.md): responsabilidades y normas para juniors, seniors y responsables técnicos.

\* \[Puertos locales oficiales](LOCAL\_PORTS.md): asignación de puertos para Gateways, BFFs y APIs de servicios.

\* \[Definition of Ready](DEFINITION\_OF\_READY.md): condiciones necesarias para comenzar una actividad.

\* \[Definition of Done](DEFINITION\_OF\_DONE.md): condiciones necesarias para considerar una actividad terminada.
